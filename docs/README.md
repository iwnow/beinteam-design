# Новый дизайн BeInTeam CRM — передача в разработку

Пакет для агента или разработчика, который соберёт рабочее приложение по макетам (Angular 21 или другой фреймворк). Макеты — статичный HTML в `new-design/`, без сборки и без бэкенда.

## Что сделано

- **Дизайн-система BeInTeam** по `Beinteam_PATI_Design.pdf` (логотип — только «BeInTeam», без «× ПАТИ»): токены цвета, шрифтов, отступов и статусов, светлая тема (основная) и тёмная — `assets/tokens.css`.
- **Библиотека компонентов** на чистом CSS — `assets/app.css`, разбита на блоки `/* === Имя === */`, каждый блок соответствует будущему компоненту.
- **Каркас и поведение макетов** — `assets/app.js`: сайдбар, топбар, мобильный таббар, стек боковых панелей, тосты, `Ctrl K`, вкладки, сегменты, чипы, deep-link `#имя`. Это демонстрация поведения, а не код для переноса.
- **13 страниц**: `index` (хаб), `login`, `dashboard` (новый экран «Сегодня»), `schedule`, `orders`, `clients`, `tasks`, `objects`, `object`, `cashbox`, `checklists`, `reports`, `settings`. 39 боковых панелей (32 уникальных id) вместо модалок.
- Проверено в браузере на 1440 и 375 px, светлая и тёмная тема: ошибок в консоли нет, все `data-drawer` ведут на существующие панели, горизонтального скролла страницы нет, внутри панелей ничего не вылезает.

## Главная идея редизайна

Текущий UI держится на модалках, вложенных до трёх уровней, плюс нижний «снэк» с формами и нативный `confirm()`. Новый UI: **просмотр, создание и редактирование — в правой боковой панели**. Контекст страницы (расписание, канбан, таблица) остаётся виден. Панели складываются стеком (бронь → оплата → ссылка). Вместо «Вы уверены?» — тост «Вернуть» или inline-подтверждение. Подробно — [03-ux-patterns.md](03-ux-patterns.md).

## Как смотреть макеты

```bash
py -3 -m http.server 5180 --directory new-design
```

Открыть `http://localhost:5180/` — хаб со ссылками на все экраны. С `file://` не открывать: относительные пути и шрифты работают только через сервер. В Claude Code есть конфиг `new-design` в `.claude/launch.json`.

Deep-link открывает панель сразу: `orders.html#order`, `schedule.html#booking`, `clients.html#client`, `tasks.html#task`, `cashbox.html#tx`.

## Структура

```
new-design/
  index.html            хаб: экраны, палитра, витрина компонентов
  *.html                экраны
  assets/tokens.css     токены (→ глобальные стили приложения как есть)
  assets/app.css        компоненты (→ глобальные утилиты + стили компонентов)
  assets/app.js         поведение макетов (НЕ переносить, переписать на фреймворке)
  docs/                 эта документация
```

## Статус

Макеты не закоммичены. Демо-данные вымышленные (см. правила в `06-markup-rules.md`). Источник правды по данным — `https://test.beinteam.ru/api/openapi.json`, по визуалу — `assets/*` и `index.html`.
