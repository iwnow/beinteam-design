# Дизайн-система BeInTeam

Источник — `Beinteam_PATI_Design.pdf`. Реализация — `assets/tokens.css` (переменные) и `assets/app.css` (компоненты). Витрина — `index.html`.

## Принципы

1. **Тёплый нейтральный фон, чёрный каркас, оранжевый — только действие.** Оранжевый (`--accent`) не используется для декора, заголовков и статусов. На экране одна главная оранжевая кнопка в шапке и одна в футере панели.
2. **На оранжевом — чёрный текст** (`--on-accent: #0b0b0b`). Белый на `#FF5A00` не проходит контраст AA.
3. **Статус = цвет + слово.** Никогда только цветом: бейдж всегда содержит текст статуса.
4. **Цифры — главное.** Деньги и время набраны крупно (`--font-display`, tabular-nums), подписи — мелко и приглушённо.
5. **Светлая тема основная**, тёмная — полноценная, меняются только токены, разметка та же.

## Цвета

| Токен | Светлая | Назначение |
|---|---|---|
| `--bg` | `#F7F5F0` (Bone) | фон страницы |
| `--surface` | `#FFFFFF` | карточки, панели, таблицы |
| `--surface-2` | `#F1EEE8` | шапки таблиц, hover, подложки |
| `--surface-3` | `#E8E5DF` | активный сегмент, выделение |
| `--surface-inverse` | `#0B0B0B` | «hero» блоки с крупной суммой (баланс, «осталось оплатить») |
| `--line` / `--line-strong` | `#E8E5DF` / `#D6D1C7` | разделители, рамки полей |
| `--text` / `-2` / `-3` | `#0B0B0B` / `#5E5A54` / `#8C877F` | основной / вторичный / подписи |
| `--accent` | `#FF5A00` | кнопка главного действия, активный пункт меню, фокус |
| `--accent-soft` | `#FFE8DA` | подложка выбранного (слот, день недели) |
| `--accent-text` | `#C24500` | оранжевый текст-ссылка на светлом фоне (AA) |
| `--side-*` | чёрный | сайдбар всегда тёмный, в обеих темах |

### Статусы

| Класс | Токены | Где используется |
|---|---|---|
| `.badge-paid` | `--st-paid` зелёный | Оплачен, Завершена, доход, «Открыта» (смена) |
| `.badge-confirmed` | `--st-confirmed` синий | Подтверждён |
| `.badge-pending` | `--st-pending` оранжево-коричневый | Новый, Ожидает подтверждения/предоплаты, В работе |
| `.badge-error` | `--st-error` красный | Отменён, Отклонена, ошибка, расход, неисправность |
| `.badge-info` | `--st-info` фиолетовый | «Перезвонить» и другие пользовательские статусы |
| `.badge` | `--st-neutral` | Черновик, Новая (задача), Закрыт, архив |

Соответствие кодам API (вынести в один словарь, например `BadgeComponent` / `statusTone(code)`):

| Сущность | Код → тон |
|---|---|
| Заказ `OrderStateCode` | `DRAFT` neutral · `NEW` pending · `WAIT_CONF` pending · `WAIT_PREPAYM` pending · `CONF` confirmed · `PAID` paid · `CANC` error · пользовательские (без кода, напр. «Перезвонить») → info |
| Задача | `NEW` neutral · `INPROGRESS` pending · `CLOSED` paid · `REJECTED` error |
| Ссылка на оплату | `NEW`/`WAITCAPT` pending · `SUCCEEDED` paid · `CANCELED` error · `REFUNDED` neutral |
| Горящее предложение | `ACTIVE` pending · `RESERVED` confirmed · `BOOKED` paid · `EXPIRED`/`CANCELLED` neutral |

У брони своего статуса нет: цвет события в расписании (`.ev-paid / -confirmed / -pending`) берётся из статуса заказа; бронь без заказа — блокировка (`.ev-blocked`, штриховка).

## Типографика

- **Onest** — заголовки, крупные цифры (`--font-display`), веса 600–700, `letter-spacing: -0.02em`.
- **Golos Text** — текст интерфейса (`--font-text`), 400/500/600.
- Шкала: `--fs-display` 38 px (30 px на мобиле) — h1 страницы; `--fs-h2` 22 — заголовок панели; `--fs-h3` 17 — секции; `--fs-body` 14; `--fs-sm` 13; `--fs-xs` 12; `--fs-money-xl` 40 — суммы в hero-блоках.
- Заголовки страниц — обычный регистр. ВЕРХНИЙ РЕГИСТР только в `.overline` (надзаголовок над h2 панели) и на экране входа.
- Деньги: `6 750 ₽` — пробел между разрядами и перед ₽ неразрывный (`&nbsp;` / ` `). Знак у операций: `+3 750 ₽` / `−1 000 ₽` (настоящий минус U+2212).
- Даты: «21 сентября · 17:00–18:00», диапазоны через en dash «–».

## Размеры

- Отступы `--sp-1..10`: 4, 8, 12, 16, 20, 24, 32, 40 px.
- Радиусы: `--r-sm` 6 (мелкие), `--r-md` 10 (поля, кнопки), `--r-lg` 14 (карточки), `--r-pill` (чипы, бейджи).
- Контролы: высота 40 px (`--control-h`), компактные 32 px (`.btn-sm`). На мобиле зона нажатия не меньше 40 px.
- Каркас: сайдбар 248 px (свёрнутый 72), топбар 56, панель 460 px (`.drawer-wide` 640), на мобиле панель 100vw.
- Тени минимальные: `--shadow-sm` для карточек, `--shadow-panel` только у боковой панели.

## Тёмная тема

- Переключение: атрибут `data-theme="dark|light"` на `<html>`; без атрибута — по `prefers-color-scheme`. В макете выбор хранится в `localStorage['bi-theme']`.
- Переопределяются только токены (`:root[data-theme='dark']` и тот же набор в `@media (prefers-color-scheme: dark)`). В компонентах нет ни одного hex — так и держать.
- Статусы в тёмной теме — светлые тексты на тёмных подложках той же семантики.
- `--accent` не меняется, `--accent-text` светлеет до `#FF8A4A`.

## Иконки и шрифты

- Lucide (в макетах `lucide@0.460.0` UMD; в приложении — пакет для фреймворка: `lucide-angular`, `lucide-react`, `lucide-vue-next`). Размер 18 px, `.ico-sm` 16 px, stroke 2.
- Шрифты в макетах — Google Fonts; в приложении — self-host (`@fontsource/onest`, `@fontsource/golos-text`), чтобы CRM работала без внешних CDN.

## Что нельзя

- Hex/rgb в стилях компонентов — только `var(--…)`.
- Оранжевый для статусов и графиков «просто для красоты» (исключение — выходные дни на графике выручки в `reports.html` как смысловое выделение).
- Белый текст на оранжевом.
- Статус только цветом, без слова.
