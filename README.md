# BeInTeam — новый дизайн CRM

Статичные макеты CRM и документация для переноса на Angular или другой фреймворк. Открываются как сайт на GitHub Pages:

```
https://<пользователь>.github.io/beinteam-design/
```

Адрес сайта — имя репозитория. Если назвать репозиторий иначе, изменится и путь.

## Как выложить

1. Создать на GitHub пустой репозиторий `beinteam-design`.
2. Отправить в него эту папку:
   ```bash
   git remote add origin https://github.com/<пользователь>/beinteam-design.git
   git push -u origin main
   ```
3. В репозитории: **Settings → Pages → Build and deployment → Source: Deploy from a branch**, ветка `main`, папка `/ (root)`.
4. Через 1–2 минуты сайт откроется по адресу выше.

Для приватного репозитория Pages доступны только на платных тарифах GitHub. На бесплатном тарифе репозиторий должен быть публичным.

## Что внутри

- `index.html` — витрина: дизайн-система и ссылки на все экраны.
- `*.html` — 13 экранов CRM (вход, «Сегодня», расписание, заказы, клиенты, задачи, объекты, кассы, чек-листы, отчёты, настройки).
- `assets/` — токены, стили и скрипт, который оживляет макеты (панели, вкладки, тосты, `Ctrl K`).
- `docs/` — документация для сборки приложения. GitHub Pages собирает её из Markdown в HTML (Jekyll), ссылки с витрины ведут на `docs/*.html`.

Все пути относительные, поэтому сайт работает из подпапки `/beinteam-design/` без настройки.

## Обновление

Источник макетов — `frontbit/web/new-design`. Чтобы перенести свежую версию:

```bash
./sync.sh            # по умолчанию берёт ../frontbit/web/new-design
git add -A && git commit -m "обновление макетов" && git push
```
